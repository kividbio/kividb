# The tests of Redis's suite KiviDB is known to fail, as "<unit> | <test
# name>", and "| io_uring" after one that fails on io_uring only.
# scripts/redis_compat.sh fails CI on any other failure, and prints a notice
# when one of these passes: take it off the list then.

# KiviDB writes every HyperLogLog dense (12304 bytes); the test corrupts a
# sparse one.
unit/hyperloglog | Corrupted dense HyperLogLogs are detected: Wrong length

# #21: OBJECT IDLETIME is 0 under noeviction unless key-access-tracking yes
# is set (off by default); the test passes with it on.
unit/introspection-2 | TTL, TYPE and EXISTS do not alter the last access time of a key

# The test expects expiring a set of 1,000,000 integers to take the expiry
# cycle over 20 ms (`expire-cycle` in LATENCY LATEST). A large set's table
# (#764) keeps integers of up to seven digits in its slots, with no block to
# free each, so the set is freed in well under a millisecond and no event is
# recorded.
unit/latency-monitor | LATENCY of expire events are correctly collected

# No timer shrinks an idle client's query buffer on io_uring; on Tokio both
# pass (docs/REDIS_TEST_SUITE.md). The second fails because the first did.
unit/querybuf | query buffer resized correctly | io_uring
unit/querybuf | query buffer resized correctly with fat argv | io_uring

# A known 1.x issue: Lua 5.4 holds more memory than Redis's 5.1 after
# loading, and used_memory_vm_functions ends just over the test's limit.
unit/scripting | Verify Lua performs GC correctly after script loading

# The tests raise `hash-max-ziplist-value` to 1,000,000,000 and compare the
# order HGETALL gives a hash of 8 KB and 64 KB values with a listpack's. The
# limit here goes no higher than 64 bytes, so that hash is a `hashtable`,
# which since #764 (hashes on `CollectionTable`) has no order, as a Redis
# hashtable has none; the fields and values are right (the tests' own sorted
# comparison passes).
unit/type/hash | Hash ziplist of various encodings
unit/type/hash | Hash ziplist of various encodings - sanitize dump
