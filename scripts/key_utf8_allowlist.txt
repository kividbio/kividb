# Places in src/commands where an argument that could be a key is
# legitimately turned into text — checked by scripts/check_key_utf8.sh
# (part of #510). One line per site or pattern: path | text the line
# contains | why the conversion is right.
#
# A key argument itself is never text: it reaches the store as bytes, and
# the test in tests/keyspec_binary_keys.rs walks the key-spec table to
# prove every command takes one of any bytes. The lines below convert a
# name that is not a key (an index, alias, dictionary, subcommand, host,
# database or count), put the key's bytes into a message, or skip a
# by-text convenience (a notification name) while the key stays bytes.
