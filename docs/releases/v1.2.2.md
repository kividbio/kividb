## What's in 1.2.2

1.2.2 is a patch release of 1.2.1 with one fix. A multi-key write over a key past its TTL (`MSET`, `MSETNX`, `JSON.MSET`, or a `MULTI`/`EXEC` of plain `SET`s) could make the whole server stop answering, `PING` included, when a search index existed and, at the same moment, an index was being changed (`FT.CREATE`, `FT.ALTER`, `FT.DROPINDEX`, an `FT.ALIAS*` command, or a vector index compacting itself) and a hash in the index was being written (`HINCRBY`, `HDEL` and the like, or a hash field expiring). The write now lets go of all of its keys before it deletes the expired ones. Servers without a search index were not affected, and neither was 1.1.

## Before you upgrade

Nothing new: 1.2.2 changes only this. What to check before upgrading from 1.2.0 or earlier is in the [1.2.1 release notes](https://github.com/kividbio/kividb/blob/v1.2.1/docs/releases/v1.2.1.md).
